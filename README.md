## ⚡ ABOUT THE PROJECT

**Mail Warden** is not just a Tic-Tac-Toe game. It is a **psychological UX experiment** designed for high-end B2B lead generation. 

Instead of a boring CAPTCHA, users must prove their intelligence by drawing or winning against a perfect Minimax Algorithm. This creates engagement, filters out bots, and increases the perceived value of the contact form.

**Edited & Designed by Sayel.**

---

## 🚀 KEY FEATURES

### 🧠 The Core Logic
* **Unbeatable AI (Minimax):** The algorithm calculates every possible move. It never loses.
* **Smart Locking System:** The email input is disabled and shakes if clicked. Only a Draw or Win unlocks it.
* **Mercy Rule:** If a user loses 3 times (0 attempts left), a hidden "Manual Override" appears to prevent user frustration.

### 🎨 High-End UI/UX
* **Glassmorphism & Aurora:** Modern, translucent UI with animated gradients.
* **3D Tilt Effect:** Cards react to mouse movement for a premium feel.
* **Responsive Design:** Works perfectly on Mobile and Desktop.

### ✨ Juice & Polish
* **Audio Synthesis:** Sound effects generated in real-time (Web Audio API) - No heavy MP3 files.
* **Visual Feedback:** Neon glows, winning line highlights, and confetti rain on unlock.
* **Terminal Simulation:** A typing-effect console that analyzes the player's psychology.

### 🌍 Internationalization (i18n)
* **5 Languages Supported:** 🇫🇷 FR, 🇬🇧 EN, 🇪🇸 ES, 🇵🇹 PT, 🇨🇳 ZH.
* **Instant Switch:** All text, including terminal logs and placeholders, translates instantly.

## 🧩 CODE STRUCTURE

The project is contained within a **single file** (`index.html`) for easy portability and deployment.

* **CSS:** Handles the Aurora animations, Glassmorphism, 3D transforms, and Shake effects.
* **JS (Game):** Manages the Minimax algorithm, game state, and score.
* **JS (UI):** Handles the "Typewriter" terminal, Sound synthesis, Confetti, and Translations.
